# Otros simuladores
_A pesar de que TJAPlayer3 es el simulador más utilizado en los últimos años, otros simuladores han sido lanzados antes de éste, y otros le seguirán en un futuro._<br>
_No se documentará mucha información sobre estos simuladores a menos que alguien voluntariamente se ofrezca a aportar contenido._

## Taiko-san Jiro
Taiko-san Jiro (太鼓さん次郎) también conocido como Taikojiro, es el primer simulador de Taiko.<br>
<a href="../assets/sim/taikojiro292.zip">Descarga aquí</a>

## Taiko-san Daijiro 2
Taiko-san Daijiro 2 (太鼓さん大次郎2) es un simulador al estilo de Taikojiro hecho para dispositivos móviles.<br>
<a href="https://apps.apple.com/ie/app/taiko-san-daijiro-2/id1183008625">App Store (iOS)</a><br>
<a href="https://play.google.com/store/apps/details?id=com.daijiro.taiko">Google Play Store (Android)</a>

## Taiko-san Nantoka
Taiko-san Nantoka (太鼓さんなんとか) es una versión de Taiko-san Jiro mucho más fluida y de mejor calidad, el cual se asimila al arcade de segunda generación Taiko no Tatsujin 14. <br>
<a href="../assets/sim/太鼓さんなんとか.zip">Descarga aquí</a>

## Taiko Unity
Taiko Unity es un simulador descontinuado hecho en Unity. Su distribución continúa actualmente. Taiko Unity ofrece un don-chan en 3d completamente personalizable y unos muy buenos gráficos. Sin embargo, es propenso a tener lag en el audio, y no puedes jugar dans personalizados o archivos .mp3.<br>
<a href="https://drive.google.com/file/d/1iZB7Y64ixbtns3eGSaj1e7S4Zl8XRl4N/view?usp=sharing">Descarga aquí</a><br>

## Taiko Web
Taiko Web es un simulador web open-source desarrollado por Bui. Tiene soporte tanto para TJAs personalizados, archivos .osu, multijugador en línea (solo dos jugadores), y un montón de otras características, todo directamente desde tu navegador. 

Taiko Web oficial: [taiko.bui.pm](https://taiko.bui.pm)
