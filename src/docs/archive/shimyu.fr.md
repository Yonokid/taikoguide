# D'autres simulateurs
_Même si TJAPlayer3 est le simulateur le plus utilisé dans ces dernières années, d'autres simulateurs l'ont précédé et d'autres lui succèderont._<br>
_Peu d'informations seront documentées sur ces simulateurs à moins que quelqu'un se porte volontaire._

## Taiko-san Jiro
Taiko-san Jiro (太鼓さん次郎) aussi connu comme Taikojiro, est le premier simulateur Taiko.<br>
<a href="../assets/sim/taikojiro292.zip">Télécharger</a>

## Taiko-san Daijiro 2
Taiko-san Daijiro 2 (太鼓さん大次郎2) est un simulateur de style Taikojiro fait pour les appareils portables.<br>
<a href="https://apps.apple.com/ie/app/taiko-san-daijiro-2/id1183008625%22%3E App Store (iOS)</a><br>
<a href="https://play.google.com/store/apps/details?id=com.daijiro.taiko%22%3E Google Play Store (Android)</a>

## Taiko-san Nantoka
Taiko-san Nantoka (太鼓さんなんとか) est une version plus fluide et de meilleure qualité de Taiko-san Jiro, qui vise à ressembler à la version d'arcade de 2e génération Taiko no Tatsujin 14.<br>
<a href="../assets/sim/太鼓さんなんとか.zip">Télécharger</a>

## Taiko Unity
Taiko Unity est un simulateur abandonné construit dans Unity. La distribution est OUVERTE. Taiko Unity offre un Don-chan 3D complétement personalisable et des très beaux graphismes. Mais il est susceptible à du décalage audio, et vous ne pouvez pas jouer des Dans personalisés ou des fichiers MP3.<br>

## Taiko Web
Taiko Web est un simulateur web et open-source développé par Bui. Il supporte les TJAs personalisés, les fichiers .osu, multijoueur en-ligne, et d'autres fonctionnalités, localisé entièrement à l'intérieur de votre navigateur. Essayez-le <a href="https://taiko.bui.pm/%22%3E ici.</a>

## TaikoPlusEX
TaikoPlusEX est un simulateur privé de style Nijiiro écrit à partir de zéro en C#, crée par Akasoko (あかそこ). 1 version est divulguée, et est disponible ici. Ce simulateur utilise DxLib à la place de SlimDX. Veuillez faire attention en téléchargeant ce simulateur à partir de sources <b>d'autres que TJADB; le développeur partage une version avec du malware.</b><br>
