# Taiko-San Daijiro 3

A Taiko simulator for mobile.

**Download (iOS):** [App Store](https://apps.apple.com/us/app/taiko-san-daijiro-3/id1183008625)

**Download (Android):** [Google Play](https://play.google.com/store/apps/details?id=com.daijiro.taiko3)

## Song Setup

1. Download songs from the [Downloading Songs](songs.md) page.
2. Locate the game's folder via your device's files app.
3. Place genre folders inside.
4. Load the game.
5. Create genres by going into the folder and pressing the "Edit" button in the top right, then "Genre Editing". `box.def` files are not supported.
