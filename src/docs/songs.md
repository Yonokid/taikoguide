# Downloading Songs

## Official Songs

### Every Song Ever (ESE)

Every official Taiko song hand crafted into TJA format!

**Download (Git):** [ese.tjadataba.se/ESE/ESE](https://ese.tjadataba.se/ESE/ESE)

For information on downloading using *Git*, please read [these instructions](https://ese.tjadataba.se/DragonRatTiger/DownloadingCharts).

### OpenTaiko Originals

OpenTaiko's original soundtrack! While these charts were created for OpenTaiko, they work on all simulators.

**Download:** [OpenTaiko/Songs](https://mew.js.cool/DownGit/#/home?url=https://github.com/0auBSQ/OpenTaiko/tree/main/OpenTaiko/Songs)

## Community Charters

### TJA Database (TJADB)

The server's namesake, a database maintained by Pidgey for the easy download of TJA files! Also included are individual pages for artists, sources, and charters. It is still a work-in-progress.

**Visit:** [tjadataba.se](https://tjadataba.se/)

### TJA Portal

A website dedicated to collecting various links & communities that create and share TJA files with other players, and sharing those links for more players to discover. This site also somewhat acts as a preservation for links that may one day become lost to time or obscurity. Please note that the website does not host TJA files, and links are provided by community members. The site is maintained by DragonRatTiger.

**Visit:** [tjaportal.neocities.org](https://tjaportal.neocities.org/)

### Song Packs

Collections of songs dedicated to specific subjects (mostly being other games). Some packs have an end-goal, while other packs are continuously updating with increasing amounts of content. Currently hosting packs for OpenTaiko, Project OutFox: Serenity, Project SEKAI, Arcaea, and WACCA. Check back frequently for when new packs get added, in case they aren't listed here.

**Download:** [tjaportal.neocities.org/packs](https://tjaportal.neocities.org/packs)

Additionally, you can search for a specific song in the TJADB Discord server by typing `in: tja-publishing: [SONG]` in the search bar.

## Song Setup (PC simulators)

Applies to OpenTaiko, TNDE, and YataiDON.

1. Download songs you like from above!
2. Navigate to the "Songs" folder.
3. Put TJA files into the Songs folder.

You can sort songs by genre by using `box.def` files, which are included in the ESE download.
